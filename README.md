## Software Design and Engineering

### Android Inventory Application
**Original course: CS 360 Mobile Architecture and Programming**

I created this Java application to manage inventory through an Android interface. The project includes login, SQLite database operations, and an SMS permission screen.

I plan to separate screen behavior, inventory rules, and database access into distinct parts of the application. For example, the app should reject an invalid quantity before attempting to save it. If a database update fails, it should explain the problem without showing the change as successful.

This enhancement will demonstrate application design, input validation, error handling, and testing.

## Algorithms and Data Structures

### ABCU Course Advising Program

This project works with course information and prerequisites to support academic advising.
